# QR-001 — Download a QR code that contains the entered content

- **Route:** `/toolbox/qr-code-generator`
- **Automation:** `website.testing.QrDownloadTest`
- **Setup:** Start the website separately and use a fresh Chromium context. Set the Java system property `website.baseUrl` if the site is not at `http://127.0.0.1:3000`.

| Step | Expected result |
| --- | --- |
| Open the QR Code Generator. | The default QR preview renders and **Download PNG** is enabled. |
| Replace **Text or URL** with spaces, a tab, and a newline. | **Download PNG** is disabled. |
| Enter `https://example.com/qr-pilot?case=QR-001` with surrounding whitespace. | **Download PNG** is enabled again. |
| Click **Download PNG** and save the browser download. | Chromium suggests `qr-code.png`, and the downloaded file is a PNG. |
| Decode the downloaded image with ZXing. | The decoded text is exactly `https://example.com/qr-pilot?case=QR-001`, without surrounding whitespace. |

The fixture URL is encoded as text only; the test does not visit it.
